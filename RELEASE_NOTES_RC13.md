# DriveCanvas 7.1.3-rc13

- Passenger app projection replaces a previous Passenger app instead of stacking duplicate tasks. Cluster and Passenger may show one separate app each.
- Home, Screens and Wallpapers now show the same startup target for each screen. Choosing app projection or wallpaper for a screen replaces that screen's earlier startup choice.
- Wallpapers is available directly on the main navigation bar.
- Required update prompts appear across main-screen DriveCanvas sections. The Update button downloads and verifies the APK from GitHub and opens Android's system installer without navigating to Update Center.

Android installation still needs the owner's confirmation, and some cars require enabling installation from DriveCanvas when prompted. The currently installed version's update screen controls the first transition to this version.

Automatic navigation-to-screen projection is a planned opt-in feature and is not enabled in this release. In-car projection performance and screen routing still need confirmation on the target car.
